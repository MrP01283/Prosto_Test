# Демонстрационные макеты сайта тестов

Откройте `index.html` в браузере. В верхней панели можно переключаться между 10 экранами и менять светлую/тёмную тему. Кнопка «Тема по макету» возвращает исходное оформление каждого экрана.

1. Каталог опубликованных тестов.
2. Личный раздел создателя: черновик, опубликованный и закрытый тест.
3. Ручное создание вопроса.
4. Вставка полного вопроса из одного текстового блока.
5. Перенос вопросов из другого теста.
6. Страница перед началом теста.
7. Прохождение теста на отдельной широкой странице.
8. Неправильный ответ с указанием выбранного и правильного вариантов.
9. Итог и разбор ошибок.
10. История попыток участника.

Это макеты интерфейса для согласования дизайна. Они не публикуют тесты и не сохраняют реальные попытки. Все примеры тестов и результатов вымышлены.
